# CN102039159A Example

This example is a small end-to-end regression case for CATDA extraction.

## Files

| Path | Purpose |
|---|---|
| `examples/CN102039159A.md` | Source Markdown text for the patent example. |
| `examples/CN102039159A_ref/graph/CN102039159A_output.json` | Published-paper reference CatGraph extraction. |
| `examples/CN102039159A_ref/dataset/CN102039159A_dataset.tsv` | Published-paper reference projected feature table. |
| `examples/CN102039159A_ref/metadata/CN102039159A_result.json` | Reference run metadata. |

The reference directory is kept as a publication reference. New tests should write to a separate output directory.

## Run Extraction And Table Generation

This command extracts both:

1. `graph/CN102039159A_output.json`: CatGraph.
2. `dataset/CN102039159A_dataset.tsv`: projected feature table generated with `prompts/features_to_extract.txt`.

```bash
export OPENROUTER_API_KEY="<your_openrouter_key>"
python extract_main.py examples/CN102039159A.md \
  --output-dir examples/CN102039159A_test_run \
  --file-ext .md \
  --mode both \
  --processes 1 \
  --model openrouter_openai/gpt-5.4 \
  --ml-model openrouter_openai/gpt-5.4 \
  --reasoning-effort medium \
  --feature-file prompts/features_to_extract.txt
```

Expected generated files:

```text
examples/CN102039159A_test_run/
  graph/CN102039159A_output.json
  dataset/CN102039159A_dataset.tsv
  metadata/CN102039159A_result.json
  scenario_response_pairs/CN102039159A/
```

## Quick Comparison

```bash
python - <<'PY'
import json
from pathlib import Path
import pandas as pd

run = Path("examples/CN102039159A_test_run")
ref = Path("examples/CN102039159A_ref")

def graph_counts(path):
    graph = json.load(open(path, encoding="utf-8"))
    return {
        section: {
            "nodes": len(data.get("nodes", [])),
            "edges": len(data.get("edges", [])),
        }
        for section, data in graph.items()
    }

print("Graph counts:")
print(json.dumps({
    "run": graph_counts(run / "graph/CN102039159A_output.json"),
    "ref": graph_counts(ref / "graph/CN102039159A_output.json"),
}, ensure_ascii=False, indent=2))

run_tsv = run / "dataset/CN102039159A_dataset.tsv"
ref_tsv = ref / "dataset/CN102039159A_dataset.tsv"
print("Dataset shape:")
print({
    "run": pd.read_csv(run_tsv, sep="\t").shape if run_tsv.exists() else None,
    "ref": pd.read_csv(ref_tsv, sep="\t").shape if ref_tsv.exists() else None,
})
PY
```
